# Contribution Guidelines

## New entry format

* Use the following format: \[TITLE by AUTHOR\]\(LINK\) [ICONs]: [DESCRIPTION]
* The link should be the name of the article, video or book.
* Provide a stars badge and last commit badge when pointing to a GitHub repo.
* Lists are generally sorted by logical learning order with newer titles first. Mostly a judgment call.
* Keep descriptions concise, clear and simple.

## Non-free notice

We have additional requirements for links that lead to a paid product or service:

* You should add the 💵 icon.

## Artificial Intelligence notice

We have additional requirements for links that lead to a content primarily created with AI:

* You should add the 🤖 icon.
