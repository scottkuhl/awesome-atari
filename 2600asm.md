# Learning

## Getting Started

* [2600 101 - A tutorial by Kirk Israel](https://www.atariage.com/2600/programming/2600_101/) 📄: So you want to be an Atari Programmer, make that 2600 sing, dance, do tricks for you? What are you, some kind of masochist?

## Books

* [Atari 2600 Programming for Newbies by Andrew Davie](https://forums.atariage.com/topic/278820-atari-2600-programming-for-newbies-the-book/) 📔: Andrew Davies' series of 25 tutorials presented together in book form for free download or print on demand.

* [Making Games for the Atari 2600 by Steven Hugg](https://8bitworkshop.com/docs/books/) 📔💵: The Atari 2600 was released in 1977, and now there's finally a book about how to write games for it! You'll learn about the 6502 CPU, NTSC frames, scanlines, cycle counting, players, missiles, collisions, procedural generation, pseudo-3D, and more. While using the manual, take advantage of our Web-based IDE to write 6502 assembly code, and see your code run instantly in the browser. We'll cover the same programming tricks that master programmers used to make classic games. Create your own graphics and sound, and share your games with friends!

* [Programming Games for Atari 2600 by Oscar Toledo Gutierrez](https://github.com/nanochess/book-Atari) 📔💵: Created in 1977, the Atari 2600 keeps inciting our imagination. Now you can learn how to program this groundbreaking game console. This book contains all the elements needed to learn the 6507 assembly language, how to control the graphic elements of the TIA, create music and sound, and a step-by-step guide to the creation of five amazing games: Game of Ball, Wall Breaker, Invaders, The Lost Kingdom, and Diamond Craze.

* [Stella Programmer's Guide by Steve Wright](https://alienbill.com/2600/101/docs/stella.html) 📔: The foundational technical reference manual for developing software on the Atari 2600 Video Computer System (VCS) written in 1979.  Also available as a [PDF](http://atarihq.com/danb/files/stella.pdf) and [book](https://www.lulu.com/en/us/shop/steve-wright/stella-programmers-guide/paperback/product-1wrgr68y.html).

* [6502 Instruction Set by Andrew Jacobs](https://6502.org/users/obelisk/6502/index.html) 📔: Provides a complete guide to the MOS 6502 microprocessor's assembly language, architecture, and programming model.  Also available as a [book](https://www.lulu.com/en/us/shop/andrew-jacobs/6502-instruction-set-guide/paperback/product-zvq87w.html),

## Courses

* [Atari 2600 Programming with 6502 Assembly by Gustavo Pezzi](https://pikuma.com/courses/learn-assembly-language-programming-atari-2600-games) 💵: Learn the basics of Assembly 6502 and computer architecture programming games for the Atari VCS platform.

## Videos

* [The Atari 2600 Video Computer System: The Ultimate Talk by Sven Oliver ('SvOlli') Moll](https://www.youtube.com/watch?v=qvpwf50a48E) 📽️: The history, the hardware and how to write programs.

* [Atari 2600 Homebrew Development by Darrell Spice Jr.](https://www.youtube.com/watch?v=T31b0-V4zKc) 📽️: The talk provides a technical overview of creating modern software for the vintage Atari 2600 console.

* [Let's Make a Game! by Five Bytes](https://www.youtube.com/playlist?list=PLlv_Fh3YbPxw0Gy6JJpzhsxjOt8lGRuJv) 📽️: Videos documenting my progress creating video games for consoles, computers, and mobile!

* [ATARI 2600 Homebrew & Assembly Programming by Alyson Reiach](https://www.youtube.com/8blit) 📽️: Welcome to 8Blit, your home for Atari 2600 programming tutorials, retro hardware deep dives, and homebrew game development. Here, the stack pointer stays hot and every clock cycle counts.
